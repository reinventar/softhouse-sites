# Modelo de apresentação para clientes

Cópia de referência de `sites/karolaine-ribeiro/apresentacao.html` (aprovada pela Dayane em 24/11/2026).
Pasta com `_` não é publicada. Para cada cliente, copie `apresentacao.html` para `sites/<slug>/apresentacao.html`
e troque textos, imagens (`img/deck/`) e planos. Não edite este modelo para um cliente específico.
